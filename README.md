# Book Reading List Application

This project is a simple web-based Book Reading List Application developed using HTML, CSS, and JavaScript.

## Features

- Add books to the reading list

- Mark books as completed

- Delete books from the list

- Display total number of books

- Display number of completed books

- Press Enter to add a book

- Responsive design for different screen sizes

## Technologies Used

- HTML

- CSS

- JavaScript

## How It Works

The application allows users to maintain a personal reading list. Users can add book titles, mark books as completed by clicking on them, and delete books when they are no longer needed.
